# AquaFlow 水瓶排序（Web 版）

一个基于网页的水排序益智游戏，点击「开始游戏」即可进入随机关卡挑战。没有关卡列表，没有难度选择——难度由系统根据你的表现动态调节，通关后才会揭晓刚才那一局是什么难度。

---

https://binbin4413.github.io/AquaFlow/

## ✨ 第二版特性（v2.0.0）

### 🎨 莫奈印象派视觉
- **莫奈真迹背景**：四幅经典作品随机淡入淡出（《睡莲》《印象·日出》《罂粟花田》《撑阳伞的女人》）
- **新艺术花瓶造型**：大喇叭口瓶颈 + 金箔装饰线的优雅瓶身
- **莫奈调色板**：十种低饱和 pastel 色调，液体带立体水彩光泽
- **睡莲池氛围**：毛玻璃面板浮在油画背景上，像画廊里的互动展品

### 🎮 核心玩法
- **隐藏难度**：每次开局随机生成关卡，玩家不知道当前难度
- **自适应难度系统（DDA）**：连胜自动升档，频繁跳过/提示则自动降档
- **正向随机生成 + BFS 验证**：确保每局可解，杜绝死局
- **无限撤销**：随时回退到上一步
- **智能提示**：基于 BFS 最短解给出最优下一步
- **跳关功能**：卡住了可以直接开新的一局
- **记忆模式（可选）**：只显示每瓶顶层颜色，下层液体被遮盖，靠记忆推理；长按瓶子可偷看一次（2 秒）

### 🖱️ 交互体验
- **点击操作**：选中瓶子 → 再点目标瓶子完成倒水
- **动画反馈**：选中上浮发光、非法操作摇晃、通关彩带飘落
- **双层背景淡入淡出**：切换关卡时旧画淡出、新画淡入
- **日夜主题**：一键切换，偏好自动记忆

### 📊 数据持久化
- 连胜纪录、总场次、胜率
- 主题偏好
- 全部存储在 `localStorage`，无需注册

## 🧩 难度模型（内部）

系统维护 5 档隐藏难度，由三维度评分：

| 档位 | 颜色数 | 空瓶数 | BFS 最短解步数 |
|-----|-------|-------|--------------|
| 入门 | 3–4 | 2–3 | 3–15 |
| 简单 | 4–5 | 2–3 | 8–25 |
| 中等 | 5–7 | 1–2 | 15–40 |
| 困难 | 6–8 | 1–2 | 20–60 |
| 极难 | 7–9 | 1 | 30–90 |

> 玩家连胜、未使用提示 → 升档；频繁跳过/提示 → 降档。

## 📝 版本历史

- **v2.2.0** — 记忆模式：开始界面可选开启，开启后每个瓶子只露出顶层颜色，下层液体被遮盖，靠记忆推理；长按瓶子可偷看一次（2 秒）；已露面的液体块倒入新瓶后保持可见
- **v2.1.2** — 倒水动画效果：液体倒入/倒出的过渡动画
- **v2.1.1** — 最后5步自动完成：当剩余最短解 ≤5 步时，系统自动以动画逐步帮玩家走完
- **v2.1.0** — 二阶目标系统：最短解=3⭐、+5步=2⭐、其余=1⭐；通关后申诉查看最短解；首页展示历史最高星级与平均星度
- **v2.0.0** — 莫奈风格第二版：印象派视觉、真迹背景画廊、新艺术花瓶、双层淡入淡出
- **v1.0.0** — 基础玩法完整版：点击交互、随机关卡、BFS 求解、自适应难度、主题切换
